# WhiteSail / 白帆

查看当前网络反应、波动与中断，在常用位置保存读数，再比较哪里连接更稳定。用于观察连接表现，不承诺修复网络，也不是 Mbps 带宽测速。

Check network responsiveness, variation and interruptions, and compare saved places on iPhone.

**平台 / Platform:** iPhone
