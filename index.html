English Support

Quick Start

  1. Open Live to see the current response, variation, interruptions, and next useful action.
  2. Open Saved Places and run a short check at a place you often use, such as a bed, sofa, desk, or custom place.
  3. Compare saved readings from the same identifiable Wi-Fi.
  4. Use Further Check when you want WhiteSail to compare the current DNS with regional public DNS candidates.
  5. Review the provider, Wi-Fi matching rule, and raw profile before choosing to install a configuration.

Why does WhiteSail ask for location permission?

iOS requires location permission before an app can read the current Wi-Fi name. WhiteSail uses the permission only to request the SSID. It does not request, store, or transmit geographic coordinates.

Does changing DNS always make the internet faster?

No. DNS mainly affects name lookups. It cannot strengthen Wi-Fi signal, expand router coverage, or increase ISP bandwidth. WhiteSail presents a measured comparison so you can decide whether a reversible trial is worthwhile.

How does the per-Wi-Fi profile work?

WhiteSail can generate a standard Apple configuration profile with encrypted DNS settings and Wi-Fi SSID match rules. Saved Wi-Fi networks can use their mapped DNS provider, while cellular data and unlisted Wi-Fi networks keep system settings. iOS requires you to inspect and confirm installation or removal in Settings.

English Privacy Policy

Effective date: July 27, 2026

WhiteSail is designed without an account, advertising SDK, analytics SDK, tracking SDK, or WhiteSail-operated backend.

Data Stored on Your Device

WhiteSail may store network readings, saved place names, Wi-Fi names, DNS mappings, and recent action results locally on your device. This data is used to show comparisons and generate the configuration you request. WhiteSail does not upload these records to a WhiteSail server.

Location Permission

iOS requires location permission before an app can read the current Wi-Fi name. WhiteSail uses this permission only to request the SSID through Apple's NEHotspotNetwork API. WhiteSail does not request, store, or transmit your geographic coordinates.

Network Checks

WhiteSail contacts public connectivity-check, speed-test, website, and DNS services to measure network behavior. Those services receive normal network request information, which may include your public IP address, request time, and the fixed representative hostname or domain being tested. WhiteSail does not read your Safari history or send your personal browsing history to DNS candidates.

The provider operating each public service controls its own logs and privacy practices. Changing DNS also means future DNS queries covered by that configuration are handled under the selected DNS provider's terms and privacy policy.

Safari Content Blocker

The WhiteSail Safari content blocker uses a local static rule list. The extension does not send browsing history to WhiteSail. It reduces requests to a limited set of known advertising and tracking domains and does not block every ad.

Configuration Profiles

WhiteSail can generate a standard Apple configuration profile containing encrypted DNS settings and Wi-Fi SSID match rules. You can inspect the raw profile before installation. iOS requires you to confirm installation and removal in Settings. WhiteSail cannot read the final installed state of a manually installed profile.

Your Controls

You can remove individual Wi-Fi mappings or clear them in WhiteSail, remove the installed profile in iOS Settings, and delete the app to remove its local app data.

中文支持

快速使用

  1. 打开“实时”，查看当前网络的反应、波动、中断和下一步建议。
  2. 打开“常用位置”，在床、沙发、桌旁或自定义位置进行一次短检测。
  3. 比较同一张可识别 Wi-Fi 下保存的位置读数。
  4. 需要时使用“进一步检查”，比较当前 DNS 与按地区选择的公共 DNS 候选。
  5. 决定安装配置前，先核对服务商、Wi-Fi 匹配规则和原始配置内容。

为什么需要位置权限？

iOS 要求 App 获得位置权限后才能读取当前 Wi-Fi 名称。白帆只用它请求 SSID，不请求、保存或传输地理坐标。

更换 DNS 一定会让网络更快吗？

不一定。DNS 主要影响域名解析，不能增强 Wi-Fi 信号、扩大路由器覆盖或提高运营商带宽。白帆展示实际测得的对比，由你决定是否进行可撤销的试用。

按 Wi-Fi 匹配的配置如何工作？

白帆可以生成包含加密 DNS 设置与 Wi-Fi 名称匹配规则的标准 Apple 描述文件。已保存的 Wi-Fi 可使用各自映射的 DNS 服务；蜂窝网络和未列出的 Wi-Fi 保持系统设置。安装和移除都需要你在 iOS 设置中检查并确认。

中文隐私政策

生效日期：2026 年 7 月 27 日

白帆不包含账号、广告 SDK、分析 SDK、追踪 SDK，也没有接收用户记录的白帆自有后台。

保存在本机的数据

白帆可能在设备本机保存网络读数、位置名称、Wi-Fi 名称、DNS 映射和最近动作结果，用于展示对比和生成你主动请求的配置。白帆不会把这些记录上传到白帆服务器。

位置权限

iOS 要求 App 获得位置权限后才允许读取当前 Wi-Fi 名称。白帆只通过 Apple 的 NEHotspotNetwork API 请求 SSID，不请求、保存或传输你的地理坐标。

网络检测

白帆会访问公共连通性检测、测速、网站和 DNS 服务来测量网络表现。这些服务会收到正常的网络请求信息，可能包括公网 IP、请求时间，以及本次测试使用的固定代表性主机名或域名。白帆不会读取 Safari 历史，也不会把你的个人浏览历史发送给 DNS 候选。

公共服务的运营方按照其自身条款和隐私政策处理日志。更换 DNS 后，配置覆盖范围内的后续 DNS 查询也会由所选服务商按其条款和隐私政策处理。

Safari 内容拦截

白帆 Safari 内容拦截扩展使用本地静态规则，不会把浏览历史发送给白帆。它只减少一小部分已知广告和追踪域名请求，不能拦截所有广告。

描述文件

白帆可以生成包含加密 DNS 设置和 Wi-Fi 名称匹配规则的标准 Apple 描述文件。你可以在安装前查看原始内容。安装和移除必须由你在 iOS 设置中确认；白帆不能读取手动安装的描述文件最终是否仍处于安装状态。

你的控制

你可以在白帆中移除单个 Wi-Fi 映射或清空映射，在 iOS 设置中移除已安装的描述文件，并通过删除 App 移除本机 App 数据。
